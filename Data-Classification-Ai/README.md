# Data Classification Using AI

## Project Description

This project is a basic Machine Learning classification model developed in Python.

The project uses the Iris Dataset and a Decision Tree Classifier to classify flowers into three categories.

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- VS Code

## Algorithm Used

Decision Tree Classifier

## Features

- Load dataset
- Understand dataset
- Display dataset information
- Split dataset into training and testing
- Train AI model
- Test model
- Predict new flower class
- Display model accuracy

## How to Run

Create virtual environment

```
python -m venv venv
```

Activate virtual environment

Windows

```
venv\Scripts\activate
```

Install libraries

```
pip install -r requirements.txt
```

Run project

```
python main.py
```

## Output

- Dataset preview
- Dataset information
- Training and testing samples
- Model accuracy
- Prediction of new flower
